# 単相PMU 試作機 Q&A 集

`PMU_Specification.md` の内容についての疑問とその回答をまとめたもの。
回路の各要素（電圧/電流フロントエンド、AAF、VCM、グランド等）の意味と役割の解説。

> **注意（v2.0変更）**：本Q&Aはv1.0（電流センサ=ZMCT103C）時点の解説。
> 仕様書はv2.0で**電流センサを シャント抵抗＋AMC3302 に変更**し、
> 負担抵抗(Rb)・Vcmバイアス(Rcm)・VCM基準回路は**廃止**された。
> 以下の Q3・Q6・Q7・Q11・Q12（ZMCT103C関連）と Q2（VCM）は**歴史的経緯**として残す。
> AAF・AGND・スター接地・デカップリング・絶縁アンプの概念解説は v2.0でも有効。

---

## Q1. 電圧タップとは？

商用100Vの電圧を測定するために **L線（ライブ線）から電圧を分岐して取り出す接続点**。

```
L ─[F]─[SW]─●─[ZMCT103C 1本貫通]─●───→ 負荷へ(L)
            │
       (電圧タップ) ← ここ
            │
       分圧(510k×3+10k) → AMC3330 → AAF → ADS131M02 ch0
N ──────────●──────────────────────────→ 負荷へ(N)
```

- 負荷へ電力を流す主線路を切らずに、その電位を高インピーダンスの分圧回路で覗き見るための分岐点。
- タップ点から **L–N間の電圧** を分圧回路（上側510k×3、下側10k、分圧比≈1/153）に渡し、
  141Vpk → 約0.92Vpk に降圧して AMC3330（絶縁アンプ）へ入力する。
- 電流が主目的の ZMCT103C（電流タップに相当）と対になる概念。

## Q2. Vcm とは？

**Vcm = Common-mode Voltage（コモンモード電圧 / 中点バイアス電圧）**。
約 **1.65V（AVDD/2 = 3.3V÷2）** に設定された基準電位。

- ADCは0〜3.3Vの片電源で動くため、±にスイングする交流（バイポーラ信号）の
  中心を電源の真ん中（1.65V）に持ち上げる必要がある。これが中点バイアス。
- **電流ch**：ZMCT103C二次出力にはDCオフセットがないので、自前でVcmを与える必要がある。
  10kΩ×2分圧＋10µFバイパスで生成（オペアンプ不要）。
- **電圧ch**：AMC3330が出力コモンモード（VDD2/2≈1.65V）を内部生成するため外付け不要。

| 項目 | 内容 |
|------|------|
| Vcm | コモンモード基準電圧 ≈ 1.65V = AVDD/2 |
| 目的 | バイポーラ信号を片電源ADCの入力範囲の中央に載せる |
| 生成 | 10kΩ×2分圧 ＋ 10µFバイパス |
| 使う所 | 電流ch（ZMCT103C入力のバイアス） |

---

## Q3. T1.S1 とは？

**T1（電流センサ ZMCT103C）の二次側端子のうちの片方**。

| 表記 | 意味 |
|------|------|
| T1 | 部品記号。電流トランス ZMCT103C |
| S1 | Secondary 1 = 二次巻線の端子①（もう片方は S2） |
| PRI | Primary = 一次側（L_NODEの電線を1本貫通＝一次1回巻き） |

- 一次：L線の電流が流れる電線を ZMCT103C のコアに1本貫通（一次巻数=1）。
- 二次：巻数比1000:1で誘起された電流が S1〜S2 間に出る。
- S1–S2間に負担抵抗 Rb=68Ω を入れて電流→電圧変換し、ADCの AIN1P/AIN1N へ。
- S1・S2はそれぞれ Rcm=10kΩ経由で VCM(≈1.65V) にバイアス。

ネットリスト: `CT_S1 : T1.S1, R7.1, R10.1, R12.1`（同じノードに繋がる端子を列挙）

## Q4. AAF とは？

**AAF = Anti-Aliasing Filter（アンチエイリアスフィルタ / 折り返し雑音防止フィルタ）**。
ADCの手前に置くローパスフィルタで、fs/2（ナイキスト周波数）より高い成分を削り、
エイリアシング（折り返し雑音）を防ぐ。

この機種の設計（差動RCフィルタ、パッシブ）:

| 項目 | 値 | 意味 |
|------|----|----|
| 直列R | 1kΩ ×2/ch | 各差動ラインに直列 |
| 差動C（Cdiff）| 47nF | カットオフ fc≈1.7kHz を決める |
| コモンモードC（Ccm）| 1nF ×2 | 同相ノイズ除去（任意）|

- fc ≈ 1/(2π·2kΩ·47nF) ≈ 1.7kHz、fs/2 ≈ 3.9kHz より十分低い。
- **電圧ch・電流chで完全同一**（位相整合のため）。PMUは電圧と電流の位相差を測るので、
  両chのフィルタ群遅延を揃える必要がある。残る群遅延は実測補償。

## Q5. ADCの入力割り当て（AIN0/AIN1）は？

**ch0とch1を間違えやすいので注意。**

| ADC入力 | 入れるもの | 信号 |
|---------|-----------|------|
| **AIN0P / AIN0N**（ch0）| AMC3330 の OUTP / OUTN | 電圧 |
| **AIN1P / AIN1N**（ch1）| ZMCT103C の S1 / S2 | 電流 |

注意点:
- 直結ではなく、必ず **AAF（1kΩ直列＋47nF差動）を経由**して入力する。
- **N_NODE はADCに入れない**。N_NODEは危険側（AC100V側）にあり、AMC3330の入力 U1.INN に行くだけ。
  ADC（安全側）が見るのは絶縁後の AMC3330 出力 OUTP/OUTN のみ。
- 電流側も S1/S2 を N_NODE には繋がず、二次は S1–S2間で完結。

## Q6. ZMCT103C は入力と出力が1つずつ？

いいえ。**二次側（出力）は必ず2端子（S1・S2）**ある（トランス巻線は両端のある線のため）。

| 側 | 端子 | 内容 |
|----|------|------|
| 一次側（PRI）| 貫通電線 | 測定対象のL線をコアの穴に1本通すだけ（巻数1）。これが「入力」 |
| 二次側 | S1 と S2 の2本 | 1000:1で誘起された電流が出る。これが「出力」 |

- 「1つに見える」のは一次側（負荷へ行くL線をコアに1回通すだけ＝通過電線）。CT自身の端子ではない。
- 二次のS1→負担抵抗(68Ω)→S2 という閉ループを作って初めて電流が測れる。1端子では経路ができない。

---

## Q7. ZMCTを貫通させた線は何につなぐ？

**特別な配線ではなく、負荷へ電流を流すL線そのもの**。CTのコアに通すだけ。

```
L ●─[F1]─[SW1]─●(L_NODE)──→（ZMCT103Cのコアを1本貫通）──→ 負荷のL端子
N ●────────────●(N_NODE)─────────────────────────────→ 負荷のN端子
```

- 線の片端：L_NODE側（F1・SW1を通ってきたAC100VのL）
- 線のもう片端：負荷（測定対象機器）のL端子
- **必ずLかNの片方だけを通す**（両方通すと電流が打ち消し合いゼロになる）。
- 貫通線（一次）とS1/S2（二次）は磁気結合のみで電気的に絶縁されている。

---

## Q8. 負荷は必要？

**はい。電流を測る以上、電流を流す負荷が必要。**

- 負荷をつなぐ → L線に電流が流れる → CTが検出 → 電流測定できる。
- 負荷なし（開放）→ 電流ゼロ → 出力もゼロ → 何も測れない。
- 電圧は負荷がなくても測れる（L-N間に電圧はかかっている）。
- 試運転は低ワット抵抗負荷から段階的に。**最大10A（>10A負荷は避ける）**。

---

## Q9. 試験につなぐ負荷（測定対象）はどのくらい？

コンセント先につなぐ実際の負荷の話。仕様書推奨は「初回は低ワット抵抗負荷から」。

| 負荷 | 例 | 電流の目安 | コメント |
|------|----|---------|---------|
| 白熱電球 | 40W / 60W | 0.4〜0.6A | 最初の試験に最適。純抵抗・力率≈1で波形がきれい |
| ヒーター | 500W〜1kW | 5〜10A | 純抵抗。大きめ電流を見たいとき |
| セメント抵抗 | 100Ω/100W等 | 1A前後 | 実験用に値を選べる |

- 最大10A（1000W）以内を厳守。`I = P / 100V` で見積もる。
- スイッチング電源・モーター・LED電球は力率が低く波形が歪むので、基本動作確認には不向き。

## Q10. 分圧後の線とN_nodeをつなぐ10kΩ（R4/Rlo）の役割は？

分圧回路の **下側抵抗（Rlo）**。上側510kΩ×3と組んで100Vを縮小する。

```
L_NODE─[510k]─[510k]─[510k]─●(VDIV_TAP)──► U1.INP
        (上側 Rhi=1.53MΩ)    │
                          [R4 10k]  ← これ（下側 Rlo）
                              │
N_NODE────────────────────────●──────────► U1.INN
```

役割:
1. **分圧比を決める**：10k/(1.53M+10k) ≈ 1/153 → 141Vpk → 約0.92Vpk（AMC3330の±1V内）。
   この値が電圧chのゲインを決めるので高精度品（0.1%/≤25ppm）が必須。
2. **N_NODE（N相）を基準にする**：下端をN_NODEにつなぐことで「L–N間電圧」を測る。N基準への戻り経路。
3. 上側を510k×3に分けるのは耐圧確保（各≈33V分担）。

## Q11. 電流チャネルのバイアス抵抗（Rcm = 10kΩ ×2 / R10・R11）は？

S1・S2をそれぞれ VCM(≈1.65V) にぶら下げ、**中点バイアスを与える**抵抗。

```
T1.S1●─┬──────────[R12 1k]─┬─► AIN1P
       [R7 68Ω]            │
T1.S2●─┴──────────[R13 1k]─┴─► AIN1N
   S1─[R10 10k]─●(VCM)●─[R11 10k]─S2   ← R10・R11 がバイアス抵抗
```

- ZMCT103C二次出力はDC基準を持たないため、S1・S2の直流動作点を1.65Vに固定する。
- 値の理由：**Rb(68Ω) ≪ Rcm(10k)** なので、二次電流はほぼ全部Rb(68Ω)を流れ、
  バイアスはするが電流→電圧変換（測定精度）には影響しない。
- 電圧ch側（AMC3330）は内部でコモンモード生成するため不要。電流ch特有の部品。

---

## Q12. 負担抵抗（Rb / R7 = 68Ω）の役割は？

CTの二次電流を「電圧」に変換するための抵抗（ADCは電圧しか測れないため）。

| 役割 | 内容 |
|------|------|
| ① 電流→電圧変換 | 二次電流を電圧に（V=I×R）。一次10A→二次14.1mApk×68Ω≈0.96Vpk（FSR ±1.2V内）|
| ② ゲイン設定 | 抵抗値で測定レンジを決める |
| ③ 二次開放の防止 | CT二次を常に閉ループにし、開放時の過電圧・破損を防ぐ |

測定レンジ別のおすすめ:

| 測りたい最大電流 | 推奨Rb | Vpk |
|----------|--------|-----|
| 〜5A | 120Ω | 約0.85Vpk（小電流を高分解能で）|
| 〜10A | **68Ω**（標準・推奨）| 約0.96Vpk |
| 〜15A | 47Ω | 約1.0Vpk（CT定格に注意・推奨外）|

- 迷ったら68Ω。0.1%・≤25ppmの薄膜抵抗を使用。

## Q13. AGND とは？

**AGND = Analog Ground（アナロググランド）**。アナログ信号系の基準電位（0V）。

- デジタル系のノイズをアナログ信号から隔離するため、GNDを2種類に分けている。

| 名称 | 何の基準か |
|------|----------|
| AGND | ADCアナログ部・VCM・AAF・アナログ信号の0V |
| DGND | STM32・SPI・デジタル回路の0V |

- ルール：**AGNDとDGNDはADS131M02(U2)の直下で1点だけ接続**（スター接地）。
  デジタルノイズ電流がアナログ領域を通らないようにしつつ、基準は共通化する。

## Q14. VCMの3.3Vはどこから取る？

**アナログ3.3Vレール（+3.3V_A）** から取る。

```
+3.3V_A─[R8 10k]─●(VCM)─[R9 10k]─AGND   ; VCMに C4 10µF→AGND
```

+3.3V_A の供給源は2択:

| | 供給源 | メリット | デメリット |
|--|--------|---------|-----------|
| ①推奨 | R1SE-0505(絶縁DCDC 5V→5V)→LDO→+3.3V_A | 低ノイズ・高精度 | 部品増 |
| ②簡易 | Nucleoの3.3V共用（省略時）| 配線簡単・省部品 | ノイズに弱い |

- 仕様書では「省略可」。まず②で動作確認 → 精度を詰めるとき①に格上げが現実的。
- **VCMの3.3VとADCのAVDDは必ず同じ+3.3V_Aレールから取る**こと。

---

## Q15. 「同じレール」とは？

**レール = 電源ライン（同じ電圧を配る配線）**。同じレールから取る＝
まったく同じ電源配線（同じノード）から枝分かれして電気を取ること。

```
            +3.3V_A レール
   電源 ──●──────●──────●──
          │      │      └─→ VCM生成(R8/R9)
          │      └────────→ ADS131M02 AVDD
          └───────────────→ AMC3330 VDD2
```

- VCMは「AVDDのちょうど半分（AVDD/2）」を作るのが目的。
- 同じレールなら電源が3.3V→3.32Vに揺れてもAVDDとVCMが同じ割合で動き、
  「VCM=AVDDの真ん中」の関係が保たれ測定誤差が出ない。
- 別レールだとVCMだけずれてオフセット誤差になる。

## Q16. C6・C7（各1nF）の役割は？

電流ch ADC入力 AIN1P・AIN1N から AGND へつなぐ、**AAFのコモンモード用コンデンサ**。

```
──[R12 1k]──┬──────► AIN1P
            ├──[C6 1nF]──AGND
          [C5 47nF]
            ├──[C7 1nF]──AGND
──[R13 1k]──┴──────► AIN1N
```

| 種類 | 部品 | 接続 | 落とすノイズ |
|------|------|------|------------|
| 差動C | C5（47nF）| AIN1P–AIN1N 間 | 差動（ノーマルモード）= 信号成分の高域 |
| コモンモードC | **C6・C7（1nF×2）** | 各ライン→AGND | コモンモード（同相）= 両線共通のノイズ |

- C6・C7は両線共通に乗るノイズ（EMI・電源由来）をADC手前でAGNDへ逃がす。
- **必ず両線に同じ値（1nF・C0G）で対称配置**。非対称だとコモンモード→差動変換でノイズ化する。
- 仕様書上は「任意」（ノイズ対策の追加オプション、省略可）。
- 電圧ch側にも対の C2・C3（1nF×2→AGND）がある。

---

## Q17. C6・C7は両線にそれぞれつなぐ？

**はい。AIN1PとAIN1Nの両線に1個ずつ（C6・C7、計2個）。** 各線が独立にAGNDへつながる。

```
──[R12 1k]──┬──────► AIN1P
          [C6 1nF]──AGND      ← C6: AIN1P から AGND へ1個
──[R13 1k]──┬──────► AIN1N
          [C7 1nF]──AGND      ← C7: AIN1N から AGND へ1個
```

差動C（C5）との違い:

| 部品 | つなぎ方 | 個数 |
|------|---------|------|
| C5（47nF）差動C | AIN1PとAIN1Nの線間に橋渡し | 1個 |
| C6・C7（1nF）コモンモードC | 各線からそれぞれAGNDへ | 2個 |

- 片方だけだと左右が非対称になり、コモンモードノイズが差動信号に化けるため、必ず両線に同値で。

# ── 電源設計編（v3.x：測定線からの自給電） ──

> **テーマ**：測定対象の商用100Vから装置自身に給電（セルフパワード）しつつ、計測精度(TVE)を落とさない電源設計。
> **最終構成**：**HLK-10M05（絶縁AC-DC 5V/2A）＋ πフィルタ ＋ 低ノイズLDO(ADP7142)**。
> 分岐は**シャント Rsh 上流(L_NODE)**、絶縁は**HLK＋AMC3330/3302の二重**、安全側フローティング。
> 関連：`PMU_Specification.md`（§1・§3・§11・§15・§19・§20 に反映済み）。

---

## Q18. 制御側の電源を、測定する商用電源から給電できる？

**A. できる。「絶縁」して「シャントより上流」から取ること。**

- 安全側(STM32/ESP32/GPS/ADC)と危険側(AC100V)は AMC3330/AMC3302 の強化絶縁で分離済み。絶縁電源で+5Vを作れば安全側はフローティング維持。
- 必須2条件：①絶縁型であること（L線から非絶縁でDC生成は禁止）②シャント Rsh より上流(L_NODE)で分岐（給電電流をRshに流さない＝電流測定に誤差ゼロ）。

```
 L ─[F1]─[SW1]─●(L_NODE)──[Rsh]──●(L_LOAD)──→ 負荷L
                 │ ▲(測定電流)
      ┌──[F2]────┘  ○上流分岐：Rshを通らない＝誤差ゼロ
   [絶縁電源]         ×下流分岐：制御電流がRshに乗って誤差
 N ───●(N_NODE)
```

---

## Q19. 商用由来の電源をADCの安全側電源に使ってもいい？

**A. 問題なし。ADCは丸ごと安全側。ただしアナログ側はノイズ対策を。**

- ADCの AVDD/DVDD は絶縁境界の安全側。絶縁電源由来ならOK。
- 注意はノイズだけ：AVDDは低ノイズ化(フィルタ＋LDO)、AGND-DGNDはADC直下1点、ESP32用に5Vバルク。

---

## Q20. トランス＋リニア電源 と HLK(絶縁AC-DCモジュール)、どっち？

**A. 精度差は小さい。入手性・部品点数で HLK-10M05 を採用。**

- 振幅精度を決めるのは**ADC内蔵Vref(1.2V)**で5Vレールではない。5Vノイズは PSRR 経由のみ。
- TVEを支配するのは電源方式でなく**シャントTCR/許容差・分圧・AMC/AAF位相・GPS/PPSタイミング**。
- トランス＋7805は低ノイズだが発熱＋トランス入手難（9V/1A級基板トランスは国内実質ディスコン）。
- → アナログはLDOで再生成するのでHLKでも実用TVE差は小さい、と判断。

---

## Q21. HLKの −Vout はアナログGNDにつなぐ？

**A. いいえ。まず DGND につなぐ。AGNDとはADC直下で1点だけ結合。**

- HLKの+5Vは ESP32(WiFiバースト)等の騒がしい系に給電 → 戻りは DGND。
- −VoutをAGND直結すると ESP32電流がアナロググラウンドを汚しTVE悪化。
- 正：**+Vout→+5V、−Vout→DGND**、AGNDはADC(U2)直下で1点結合。

---

## Q22. NUCLEO＋ESP32＋GPS HAT の給電に HLK-5M05(1A)で足りる？

**A. 足りない。HLK-10M05(2A)を推奨。**

| デバイス | 平均 | ピーク |
|----------|:---:|:---:|
| NUCLEO-F446RE | ~120mA | ~150mA |
| ESP32 | ~120mA | ~500mA(瞬時~600mA) |
| L76K GPS HAT | ~40mA | ~50mA |
| アナログ系(ADC/AMC+LDO) | ~50mA | ~80mA |
| **合計** | **~330mA** | **~0.8A** |

- 5M05=1Aはピークに肉薄＋温度ディレーティング＋過渡応答が悪い → 実質不足。10M05(2A)で2倍余裕。

## Q23. 正直トランスで作った方が精度いいよね？

**A. 原理的には低ノイズ。ただしこの設計では差が小さい。**

- 理由：①振幅精度はVref依存 ②アナログはLDOで再生成しバッファ ③ΔΣ＋AAFが帯域外ノイズを除去。
- より効く一手は電源方式より「アナログ電源の分離」「シャント/分圧の精度・校正」。

## Q24. 7805 とは？（※最終的にHLK採用で不要）

- 入力を安定+5Vにする三端子リニアレギュレータ。3ピン(IN/GND/OUT)。低ノイズだが**余剰電圧を熱で捨てる**((入力-5V)×電流)。3W級は放熱器必須、熱源はシャント/分圧から離す(熱ドリフト対策)。
- トランス選定は 100V:9V/8〜10VA/強化絶縁だが、9V/1A級基板トランスは国内実質ディスコン(豊澄HT系生産終了、秋月はHT-1205=0.5A止まり)。→ **トランス+7805案は破棄、HLK-10M05に決定**。

---

## Q25. アナログ3.3Vは R1SE(絶縁DC-DC) と 三端子(LDO) どっち？

**A. LDO一段が良い（R1SEは廃止）。**

- R1SEは安全絶縁の役ではない(それはHLK/AMCが担当)。役割はノイズ絶縁のみ。
- R1SE自身がSWノイズ源で結局LDOで掃除が要る → 最初からLDO一段が素直・低ノイズ・部品減。
- LDOのPSRR(DC〜系統高調波で60〜80dB)＋ΔΣ/AAFで十分クリーン。
- フォールバック：ESP32グラウンド雑音が実測で問題化した時のみR1SE復活でアナログGND島化。

## Q26. 仕様書の全体点検（見つけて反映した修正）

1. **シャント値の矛盾**：§11だけ「3mΩ」→他は1.5mΩ → **1.5mΩ/≥1Wに統一**。
2. **有効電力の係数**：DFT `X=(2/N)Σ…` は|X|=ピーク振幅 → **RMS化(=|X|/√2)、P=Vrms·Irms·cosφ**（C37.118は振幅=RMS慣例）。
3. **シャントTCR**：§5(≤75ppm)/§11(≤25ppm) → **≤25ppmに統一**。
4. **シャント電力定格** → **≥1Wに統一**。
5. **§10ピン表に ADC /SYNC-RESET(PC0)** 追加。
- 確認済で問題なし：AMC3330ゲイン=2.0(DS一致)、AMC3302=41、AAF fc≈1.7kHz、fDATA=7812.5SPS。

## Q27. HLK周りのフィルタ用コンデンサのつなぎ方は？

**A. どのCも「片脚=電源レール／もう片脚=DGND」。直列に入るのは L1 だけ。**

```
 HLK +Vout ●──┬──[ L1 ]──┬────────┬────────┬──→ 各負荷
             (+5V)      (+5V_F)   │        │
              │  │       │        │        │
            C43 C45     C46      C44      C16+C17
           100µF 10µF   10µF   470-1000µF 10µF+0.1µF
           (電解)(ｾﾗ)    (ｾﾗ)   (ESP32直近) (LDO入力)
              │  │       │        │        │
 HLK −Vout ●──┴──┴───────┴────────┴────────┴──● DGND
              ↑π入力側    ↑π出力側
```

- π型フィルタ = **C(入力)‑L‑C(出力)**。C43/C45=π入力、L1=直列、C46=π出力。
- ルール：①全部レール↔DGND ②電解は極性あり(−をDGND) ③大容量電解＋小容量セラミック並列 ④C44はESP32直近・C16/C17はLDO直近。
- ノイズは「Cで落とす→Lで堰き止め→LDOで磨く」の3段でADC基準まで届かせない。

## Q28. ESP32付近に既に100u/10u/0.1uFがある。470uも追加？

**A. 4個目を必ず足す必要はない。狙いは「ESP32近くのバルク合計を470µF級」にすること。**

- 100µFと470µFは同じ担当(低周波バルク)。0.1/10µFは高〜中周波担当なので残す。
- 選択A：**100µF→470µFに大型化**(推奨)。選択B：100µFに470µF並列(余裕重視)。
- まず今のままテスト → 送信でリセット/+5Vがガクッと落ちるなら大型化。

---

## Q29. フェライトビーズ(L1)のおすすめは？「470-1000」の意味は？

- **「470-1000」＝470µF〜1000µFの範囲で1個を選ぶ**意味(2個ではない)。まず470µF、足りなければ1000µF。
- **L1は全電流(連続~1A/ピーク~2A)が流れる** → **電源用(大電流)ビーズ**(信号用0603はNG)。
  - 基準：**1206以上／定格≥2A(できれば3A)／DCR≤50mΩ／100〜600Ω@100MHz**。
  - 例：村田 BLM31シリーズ、TDK MPZ2012シリーズ の高電流品。
- ビーズは高周波ハッシュ用。リプル(数十〜数百kHz)まで抑えたいなら小型パワーインダクタ4.7〜10µH/≥2Aに格上げ(最後はLDOが除去するのでまずビーズで十分)。

## Q30. アナログLDOは ADP7174 シリーズなら何でもいい？

**A. ADP7174 は存在しない(型番違い)。ADP7142 か ADP7118 の 3.3V固定品を選ぶ。**

- 近い実在品：ADP7142(40V/200mA)、ADP7118(20V/200mA)、ADP7104(500mA) 等の低ノイズCMOS LDO。
- 「シリーズなら何でも」ではなく：①出力3.3V固定品(末尾 -3.3) ②出力電流が足りる(本用途~80mA→200mA品で十分)。
- おすすめ：**ADP7118AUJZ-3.3** または **ADP7142ACPZ-3.3 / AUJZ-3.3**。

## Q31. ADP7142 のピンは何につなぐ？（TSOT-23-5 / 3.3V固定）

| ピン | 名前 | つなぐ先 | 補足 |
|:---:|------|---------|------|
| 1 | VIN | **+5V_F**(πフィルタ後) | 入力C **≥2.2µF**(C16 10µF)をGNDへ |
| 2 | GND | **AGND** | このLDOはアナログ系電源 |
| 3 | EN | **VIN(=+5V_F)に直結**(常時ON) | 開放不可。制御したいならGPIOへ |
| 4 | SENSE/ADJ | **VOUT(5)に接続**(負荷点) | 固定品は出力へ繋ぐだけ |
| 5 | VOUT | **+3.3V_A**(ADC AVDD/AMC VDD2) | 出力C **≥2.2µF** をGNDへ |

- グラウンド：入力Cのコールド→DGND、GNDピン・出力Cのコールド→AGND。AGND-DGNDはADC直下1点。
- **【要修正】出力C18=1µFはADP7142要件(≥2.2µF)未満** → **2.2µF以上(例2.2〜10µF)に変更**。

## Q32. SS（ソフトスタート）ピンはどうする？

**A. 「開放(未接続)」でOK。GNDには絶対繋がない。もしくはSSピンの無いTSOT品を選ぶ。**

| パッケージ | SSピン | 対応 |
|-----------|:---:|------|

```
測定線 L_NODE ─[F2 0.5A]─ HLK-10M05(AC100V→DC5V 2A) ═絶縁═ +5V
   └ 分岐はシャント上流(電流測定に影響なし)          │
                                                    ├─[C43/C45]─[L1 ﾋﾞｰｽﾞ≥2A]─[C46]─ +5V_F
   +5V_F ─┬─→ Nucleo(E5V, JP5=E5V)
          ├─→ ESP32(+5V, バルク470µF級を直近)
          └─→ ADP7142(3.3V固定LDO) ─ +3.3V_A ─→ ADC AVDD / AMC3330・3302 VDD2
```

## Q33. 負荷抵抗10Ωを100Vに直列/直結すると発熱は大丈夫？

**A. ダメ。1000W発熱する。**

- `I = V/R = 100/10 = 10A`、`P = V²/R = 100²/10 = 1000W`。
- 10Ωは小型電気ヒーター並みの発熱 → 普通の抵抗器では焼損・発火。しかも10Aは測定レンジ上限ぎりぎり。
- 発熱は抵抗値だけで決まる（P=V²/R）。小さい抵抗ほど大電流＝大発熱。

| 抵抗 | 電流 | 発熱 | 判定 |
|------|:---:|:---:|------|
| 10Ω | 10A | 1000W | ❌ 論外 |
| 100Ω | 1A | 100W | ○（電球100W相当）|
| 470Ω | 0.21A | 21W | ◎ 初回向き |
| 1kΩ | 0.1A | 10W | ◎ 最安全 |

- ※シャント(1.5mΩ)は「負荷」ではなくセンス抵抗（10Aでも0.15W）。混同しない。

---

## Q34. 470Ωならできる？

**A. できる。470Ω/50W品でOK（発熱21W、余裕2.4倍）。ただし熱くはなる。**

- `I=100/470≈0.21A`、`P≈21W` → **50W定格の無誘導電力抵抗**で安全（§14想定どおり）。
- 扱い：開放空間/放熱器で使用、可燃物に触れさせない、素手厳禁（表面100〜150℃）。定格は発熱の2倍以上。
- 測定上の注意：0.21Aだと電流chの信号は **ADC FSRの約1.5%** と小さい（シャント両端≈0.45mVpk→×41≈18.5mVpk）。
  - ◎ 既知抵抗の振幅校正基準／力率≈1の位相校正。△ 電流ダイナミックレンジ確認には不向き。
  - 強い電流信号が欲しいときは 100W電球(≈1A) の方がSNR良好。

## Q35. 電流計測を削除した Version 2（電圧のみ）仕様書

**A. `PMU_Specification_V2_VoltageOnly.md` を作成。**

- **削除**：シャント Rsh／AMC3302(U5)／電流ch AAF(R12/R13/C5-C7)／ADC ch1／電力量(P/Q/力率)／電流校正／電流用テスト負荷。
- **ADC**：ADS131M02 の **ch0のみ**使用（1ch版 ADS131M01 でも可）。
- **出力**：Vmag(RMS)/Vang/f/ROCOF のみ。
- **引き継ぎ**：電圧FE(分圧+AMC3330)、AAF、GPS、**自給電電源(HLK-10M05＋πフィルタ＋ADP7142)**、C37.118。
- **楽になった点**：①シャント無しで自給電の分岐位置が自由（「シャント上流」制約消滅）②電圧のみなので**負荷不要**（開放でも測れる）。

## Q36. KiCad：GNDピンを接続しないと、べたGNDに自動で繋がる？

**A. 繋がらない。「接続しない＝どこにも繋がっていない（ERCエラー）」。**

- ネットは回路図で明示的に繋いだ所しか接続されない。べたGNDは**GNDネットのパッドだけ**を繋ぎ、他ネット/無所属パッドはクリアランスで避ける。
- 例：抵抗のマイナス側を何も繋がない → 浮く（フローティング）。近くにベタがあっても繋がらない。
- 唯一の「自動」＝**電源ポートシンボル（GND/+3.3V等）は同名なら配線なしで結合**。ただしピンにそのシンボルを"置く"必要はある。
- 対策：GNDにしたいピンには必ずGNDシンボル/配線を付け、ERC＋DRC(未接続チェック)で浮きゼロを確認。

## Q37. べたGNDはアナログGNDとデジタルGNDどっち？領域で塗り分ける？

**A. 「全面どちらか一色」ではない。分けなくてもいい（統一GND1枚が推奨）。**

- 一番おすすめ：**ベタを分割せず統一GND1枚**にして、**部品配置**でアナログ/デジタルを分離（ΔΣ ADCの定石。2層試作で事故が少ない）。
- 仕様書どおり分割する場合：**その場所の下の回路のGND**を塗る（アナログ部下=AGND、デジタル部下=DGND）、ADC直下で1点接続。
- 分割の落とし穴：**信号が分割線をまたぐと戻り電流が遠回りしてかえってノイズ源**。またぎ配線ゼロを徹底できないなら分割しない方がマシ。
- **判定**：分けなくてもよい（分けてはいけない訳ではない）。迷うなら統一GND1枚。

## Q38. べたGNDをDGNDで塗りつぶせばいい？

**A. 塗るネットは1つでよいが、旧AGNDピンも同じネットに繋ぎ替えること。**

- 全面をDGNDで塗るなら、**AGNDピン(ADC AVDD戻り・AMC GND2・LDO出力C・分圧Rlo戻り等)も全部そのネットに入れる**。別ネットのままだとAGNDピンがベタから浮く（島になる）。
- 一番きれい：回路図で **AGND/DGNDを「GND」1ネットに統一**して塗る。名前はGNDに一本化推奨。

---

## Q39. アナログGNDが（DGNDベタから）浮いてても、全AGNDを繋いでDGNDと1点結線すれば大丈夫では？

**A. 正しい。それが正しい分割グランド（スター接地）。AGNDは浮いていない。**

- 「浮く」のは **AGNDに専用の銅を与えず、DGNDベタが運んでくれると誤解した時**だけ。
- **AGND専用の銅（配線 or 別ゾーン）で全AGNDピンを繋ぎ、DGNDと1点で結線**すれば問題なし（DGNDベタが運ぶのではなく、AGND導体を自分で用意する）。
- KiCad実装：AGNDゾーン/配線＋**AGND–DGNDを1点だけ**結線（別ネット直結はDRCがショート判定するので**net-tie**等を使う）。信号は分割線をまたがない。

| やり方 | 可否 |
|--------|------|
| AGND専用銅＋DGNDと1点結線 | ✅ 分割の定石 |
| DGNDだけ塗りAGNDに銅を与えない | ❌ AGND浮く |
| 全部GND1ネットに統一 | ✅ 一番簡単 |

---

## Q40. net-tieじゃなくて0Ω抵抗でもいい？

**A. OK。0Ω抵抗はAGND-DGND 1点結線の定番。**

| | 0Ω抵抗 | net-tie |
|---|--------|---------|
| ネット分離(DRC OK) | ✅(2ネットを橋渡し) | ✅ |
| BOM部品 | 要1個 | 不要(銅のみ) |
| 追加インピーダンス | ≒0 | ゼロ |
| 融通 | ◎ 後でﾋﾞｰｽﾞ/DNPに差替可 | 固定 |

- KiCad的に0Ω抵抗は「2パッドが別ネットの実部品」なのでDRCのショートエラーは出ない。
- コツ：**ADC直下に1個だけ**置き、**AGND-DGND接続はこの0Ωだけ**にする。0402〜0805で十分。
- 注意：ΔΣ ADCでは AGND-DGND間は **0Ω(実質直結)推奨**。フェライトビーズ常設は避ける（両GND間電圧差が誤差要因）。切り分け用に「まず0Ω、必要時だけビーズ」。

---

*(グランド設計：この規模なら「統一GND1枚＋配置分離」か「分割＋0Ωで1点結線」のどちらでも可。またぎ配線ゼロが守れないなら統一GNDが安全。)*
