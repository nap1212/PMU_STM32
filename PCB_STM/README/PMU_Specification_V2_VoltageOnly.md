# 単相PMU 試作機 仕様書 — Version 2（電圧のみ / 電流計測なし）

**対象**：単相100V（コンセント地点）の**電圧**同期フェーザ計測装置（ラボ試作・教育/研究用）
**版**：V2.0（本体 `PMU_Specification.md` v3.2 から **電流計測部（シャント/AMC3302/電流ch）を削除**した派生版）
**構成方針**：STM32で決定的サンプリング＋フェーザ演算／ESP32でWiFi送信／GPSで時刻同期／測定線から自給電

> **本体との違い（削除したもの）**：
> - **電流シャント Rsh**、**電流用絶縁アンプ AMC3302(U5)**、**電流ch AAF(R12/R13/C5/C6/C7)**、**ADC ch1(AIN1)** を削除。
> - アルゴリズムから **電力量(P/Q/力率)** と **電流の校正** を削除。フェーザは **電圧のみ（Vmag/Vang/f/ROCOF）**。
> - **シャントが無いため「分岐はシャント上流」という制約が消滅** → 自給電のAC入力は L-N から自由に分岐可。
>
> **本体から引き継ぐもの**：電圧フロントエンド（分圧＋AMC3330）、AAF、ADC（ADS131M02, ch0のみ）、GPS時刻同期、
> **自給電電源（HLK-10M05＋πフィルタ＋ADP7142 LDO）**、C37.118出力。

## 2. システムブロック図

```
        危険側(AC100V, 測定線)          ┊絶縁┊            安全側(フローティング)
 L ─[F1]─[SW1]─●(L_NODE)───────────────────────────────→ 負荷へ(L)/開放可
              │  │
              │ (電圧タップ)
              │ 分圧(510k×3+5.1k)→ AMC3330(絶縁+DCDC) ─────────→ AAF → ADS131M02 ch0
   ┌──[F2]────┘  │                                                          │SPI/DRDY
   │(電源分岐)    │   ┊電源側の絶縁境界(HLK内蔵)┊                             │
 [HLK-10M05]─────┼─→ +5V(2A) ─┬─→ Nucleo(STM32) ──────────────────────────┤
 絶縁AC-DC 5V/2A  │            ├─→ ESP32 ─WiFi→ PC/PDC
   │            │            └─→ ADP7142→+3.3V_A(アナログ: ADC/AMC)
 N ●───────────●(N_NODE)────────────────────────────────→ 負荷へ(N)
        L76K GPS HAT ─UART/PPS─→ STM32(入力キャプチャ)   ↑MCO(8MHz)→ADC CLKIN
```

- **絶縁境界（信号）**：電圧ch＝**AMC3330**（容量結合の強化絶縁＋内蔵DC-DC）。
- **絶縁境界（電源）**：**HLK-10M05**。AC入力＝危険側、DC出力＝安全側。安全側は**二重絶縁**でフローティング。
- **電圧のみ**：センサ→絶縁アンプ→AAF→ADC ch0。出力コモンモードはAMC3330が自己生成（VDD2/2）。
- **負荷は任意**：電圧測定は L-N 間電圧を見るだけなので、負荷が無く（開放）ても測れる。

## 3. 電源アーキテクチャ（測定線からの自給電）

**電源フロー**：
```
測定線 L_NODE ─[F2]─ HLK-10M05(AC100V→DC5V 2A) ═絶縁═ +5V
   └[C43/C45]─[L1 大電流ﾋﾞｰｽﾞ≥2A]─[C46]─ +5V_F ─┬─→ Nucleo(E5V, JP5=E5V)
                                                  ├─→ ESP32（+5V, バルク470µF級を直近）
                                                  └─→ ADP7142(3.3V固定LDO) ─ +3.3V_A（ADC AVDD / AMC VDD2）
```

| レール | 供給先 | 供給元 |
|--------|--------|--------|
| （AC入力） | HLK-10M05 Vin(L/N) | 測定線 L_NODE-N_NODE（**シャントが無いので分岐位置は自由**）、F2で保護 |
| +5V / +5V_F | ESP32 / LDO入力 / Nucleo(E5V) | **HLK-10M05 出力 5V/2A**（自給電・絶縁済） |
| +3.3V（デジタル） | STM32 / ADS131M02 DVDD / L76K | Nucleo 3.3V（E5V経由の内蔵LDO） |
| +3.3V（アナログ） | ADS131M02 AVDD / **AMC3330 VDD2** | **+5V_F → ADP7142(3.3V固定LDO)** |

- **消費見積り**：Nucleo ~150mA / ESP32 ~120mA(ピーク~500mA) / GPS ~40mA / アナログ ~30mA → 合計約 **0.3A(平均)/0.7A(ピーク)**。HLK-10M05(2A)で余裕。
- **ノイズ対策**：HLK出力に**π型フィルタ（C-L-C）**＋アナログは**ADP7142(低ノイズLDO)** で再生成 → HLKのSWノイズをADC基準へ入れない。
- グラウンド：**HLK −Vout=安全側基準（DGND, フローティング）**。AGND-DGNDはADC直下1点スター。
- （電流計測が無いため、シャント・VCM基準・負担抵抗は一切不要。）

### 3.1 HLK周りのフィルタ配線

```
 HLK +Vout ●──┬────────┬──[ L1 ]──┬────────┬────────┬──→ 各負荷
             (+5V)     │  ﾋﾞｰｽﾞ  (+5V_F)   │        │
              │        │  ≥2A     │        │        │
            C43(100µF) C45(10µF)  C46(10µF) C44      C16+C17
             │        │           │     470-1000µF  10µF+0.1µF
 HLK −Vout ●──┴────────┴───────────┴────────┴────────┴──● DGND
              ↑π入力側              ↑π出力側  ↑ESP32直近 ↑LDO入力
```

- 全コンデンサの片脚は DGND。直列素子は L1 のみ。電解は極性注意（−をDGND）。
- **L1**：大電流フェライトビーズ（1206以上/定格≥2A/DCR≤50mΩ/例 村田BLM31）or 4.7〜10µH/≥2Aインダクタ。

### 3.2 ADP7142（TSOT-23-5, 3.3V固定）ピン接続

| ピン | 名前 | つなぐ先 |
|:---:|------|---------|
| 1 | VIN | +5V_F（入力C≥2.2µF＝C16 10µF/C17 0.1µF→DGND） |
| 2 | GND | AGND |
| 3 | EN | VIN(=+5V_F) に直結（常時ON） |
| 4 | SENSE/ADJ | VOUT(5) に接続（負荷点） |
| 5 | VOUT | +3.3V_A（出力C≥2.2µF＝C18 10µF/C19 0.1µF→AGND） |

- SSピンはTSOT-23-5には無い（起動~380µs固定）。LFCSP品なら開放（GND直結禁止）。

## 4. 電圧フロントエンド設計

AMC3330：±1Vバイポーラ入力（中点バイアス不要）・**固定ゲイン2.0**（データシート確認済）。
分圧比は「ゲイン2倍後の出力がADC FSR(±1.2V)に収まる」よう設定。

| 部品 | 値 | 計算/備考 |
|------|----|----------|
| 分圧 上側 Rhi | **510kΩ ×3 直列（1.53MΩ）** | 各≈33V分担で耐圧確保。0.1%/≤25ppm/薄膜 |
| 分圧 下側 Rlo | **5.1kΩ** | 分圧比 ≈ 1/301 |
| 入力ピーク | 141Vpk ÷301 ≈ **0.47Vpk** | AMC3330 ±1V内 |
| AMC出力（×2）| 0.47Vpk×2 ≈ **0.94Vpk** | ADS131M02 FSR ±1.2V内（約22%余裕）|
| 分圧電流 | 約65µA（消費約6.5mW） | Rhiでほぼ決まる |
| 出力コモンモード | AMC3330が VDD2/2（≈1.65V@3.3V）を生成 | ADC入力CMに整合 |

- **重要**：`141Vpk × 分圧比 × 2 ≤ 1.2V` を満たすこと。510kΩは working voltage ≥33V/本。

## 5. アンチエイリアスフィルタ（AAF）

電圧ch差動RCフィルタ（パッシブ）。

| 部品 | 値 | 備考 |
|------|----|----|
| 直列R（各ライン） | **1kΩ ×2**（0.1%/薄膜） | R5/R6 |
| 差動C（Cdiff） | **47nF**（C0G/NP0 or フィルム） | fc_diff ≈ 1/(2π·2kΩ·47nF) ≈ **1.7kHz** |
| コモンモードC（Ccm） | **1nF ×2**（C0G） | 各ラインからAGNDへ（任意） |

- fc≈1.7kHz は fs/2（≈3.9kHz）より十分下。50Hzで約−1.7°の群遅延 → **実測補償**。
- （電流chが無いため「両ch同一化」は不要。ただし群遅延は絶対位相（UTC基準）に効くので校正で補償。）

## 7. 時刻同期（L76K GPS HAT）

- HATはPi用だが、**UART(TX/RX)・PPS・電源・GND をSTM32へ配線**して使用（Piに挿さない）。**PPSピンが端子に出ていることを確認**。
- L76K：GPS/GLONASS/BeiDou/**QZSS対応**、1PPS精度 <30ns（50Hzで約0.0005°相当）。
- **PPS → STM32タイマ入力キャプチャ**（sub-µsでエッジ時刻取得）。UARTでNMEA受信。屋外/窓際で運用。

## 8. 制御・通信

- **STM32 → ESP32：UART（例 921600bps）**で電圧フェーザ結果（タイムスタンプ・V振幅/位相・f・ROCOF）を転送。
- **ESP32**：受信データを **C37.118.2 フレーム化 → WiFi(UDP/TCP)** でPC/PDCへ。
- 両者3.3Vロジック・GND共通、レベルシフト不要。時刻クリティカルパスはSTM32内で完結。

## 11. アルゴリズム

### 11.1 取得（Acquisition）
1. STM32がMCOで8MHzをADC CLKINへ供給 → ADCは固定 fDATA(≈7812.5SPS) で自走。
2. **DRDY割込**ごとにSPI/DMAで **ch0（電圧）サンプル** を取得し、リングバッファへ。
3. **PPS立ち上がり**をタイマ入力キャプチャで捕捉 → タイマカウントを保持。
4. サンプルカウンタとPPSキャプチャ値から、各サンプルの**絶対時刻（UTC）**を復元（PPS毎に基準更新）。

### 11.2 フェーザ推定（Phasor Estimation）
- 報告周期（例 50 fps、設定可）ごとに、UTC基準時刻に整列した窓のサンプルを抽出。
- 基本波フェーザを **DFT** で算出：
  - `X = (2/N) Σ x[n]·e^(−j2πk0 n/N)`（k0＝基本波ビン）
  - この正規化で **|X|＝ピーク振幅**、位相 = arg(X)。**C37.118は振幅=RMS慣例** → **Vrms=|X|/√2**。
- **補間DFT（IpDFT）**：Hann窓＋ピーク近傍2〜3ビンから真の周波数・振幅・位相を補間。

### 11.3 周波数・ROCOF
- IpDFTで得た基本波周波数 f を出力。連続推定値から **ROCOF = df/dt**（平滑化付き差分）。

### 11.4 校正補償（適用順）
1. **振幅スケール**：分圧比・**AMC3330ゲイン**の実測係数で物理量へ換算。
2. **位相オフセット補償**：電圧chの遅れ（AMC3330＋AAF＋ADC）を校正テーブルで減算。
3. **AAF群遅延補償**：実測群遅延を位相から差し引く。

> **削除**：電力量(P/Q/力率)、電流の振幅/位相校正（電流chが無いため）。

### 11.5 出力（C37.118）
- STM32 → ESP32（UART）：`{UTCタイムスタンプ, Vmag(RMS), Vang, f, ROCOF, status}`。
- ESP32：C37.118.2 データフレーム化 → WiFi送信（電圧フェーザのみ）。

---

## 12. 校正手順（TVEを決める要）

1. **振幅校正**：既知の基準電圧を入力し、スケール係数を決定。
2. **位相校正**：基準電圧に対する電圧chの位相オフセットを実測 → テーブル化（残差はAAF群遅延が主成分）。
3. **群遅延校正**：AAFカットオフ確定後、群遅延を実測し補償。
4. **検証**：基準器で電圧TVE・周波数精度を確認。

## 14. 安全設計（必須）

- L側に**ヒューズ（AC250V・T・ceramic HBC）＋電源SW**（F1/SW1）。**電源分岐にも専用ヒューズ F2**。
- 危険側（分圧器・**HLK AC入力側**・配線）は**絶縁ケース＋端子カバー**で露出させない。
- 絶縁境界（**AMC3330・HLK-10M05**）より先が安全側 → PC/WiFiデバッグ安全。
- **自給電の絶縁**：安全側は **HLK（電源）＋AMC3330（信号）の二重絶縁**で測定線からフローティング。非絶縁トランスレス電源は**禁止**。
- HLKのAC入力ピン（危険側）とDC出力ピン（安全側）を基板上で明確分離・絶縁距離確保。
- （シャントが無いので活線シャント配線の注意は不要。分圧器の高抵抗は感電エネルギーが小さいが、危険側電位であることに変わりないので露出させない。）

### B. 電圧チャネル（AMC3330）
```

                                       │
                                     [R4 5.1k]
                                       │
```

## 17. 要確認事項（データシート）

- **AMC3330**：固定ゲイン2.0・出力コモンモード値・DC-DCピン結線とデカップリング推奨部品。
- ADS131M02（またはADS131M01）：CAPピン等の推奨デカップリング、入力コモンモード範囲、OSR設定、**未使用ch1の処理**。
- **HLK-10M05**：AC入力範囲・絶縁耐圧・出力2A・出力リプル/ノイズ実測値・ピン配置。
- **ADP7142**：3.3V固定品番・入出力C≥2.2µF・EN/SENSE結線。
- L76K GPS HAT：PPSピンの引き出し位置、UART電圧レベル。
- STM32 MCO：8MHz出力設定（HSE経由）とADC CLKIN要件の整合。
