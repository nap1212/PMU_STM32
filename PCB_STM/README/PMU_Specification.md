# 単相PMU 試作機 仕様書 (Specification)

**対象**：単相100V（コンセント地点）の同期フェーザ（電圧・電流）計測装置（ラボ試作・教育/研究用）
**版**：v3.2（アナログ3.3Vを **R1SE-0505廃止 → 低ノイズLDO一段** に簡素化）
**構成方針**：STM32で決定的サンプリング＋フェーザ演算／ESP32でWiFi送信／GPSで時刻同期／**測定線から分岐して装置自身に給電**

> **v3.2からの主な変更**：アナログ系電源（ADC AVDD / AMC VDD2）の生成を「R1SE-0505（絶縁DC-DC）＋LDO」から **低ノイズLDO一段** に変更。
> - この設計では安全絶縁は HLK と AMC3330/3302 が担うため、**R1SEの役割は“ノイズ絶縁”のみ**。R1SE自身がスイッチングノイズ源で結局LDOで掃除が要る → **最初からLDO一段の方が素直で低ノイズ・部品減**。
> - 振幅精度はADC内蔵Vref(1.2V)が決め、5Vノイズは PSRR 経由のみ。LDOのPSRR（DC〜系統高調波で60〜80dB）＋ΔΣ/AAFで十分クリーン。
> - フォールバック：**ESP32のグラウンド雑音がアナログ基準を揺らすのが実測で問題化した場合のみ**、R1SE（絶縁DC-DC）を復活してアナロググラウンドを島化する余地を残す。
>
> **v3.1（継続）**：自給電の電源部は **絶縁AC-DCモジュール HLK-10M05（AC100V→DC5V 2A）**。トランス T3＋整流＋三端子7805 を1個に集約（部品点数・発熱を削減）。容量2Aはピーク約1Aに対し余裕（5M05＝1Aは不足）。**分岐点はシャント Rsh 上流（L_NODE）で不変**。USBはデバッグ用途で併用可。

> **v2.0→v3.0**：外部USB/5V給電に代えて**測定対象の商用100Vから装置電源を自給**する構成を標準化（分岐はシャント上流）。
>
> **v1.0からの主な変更（継続）**：電流センサを ZMCT103C（電流トランス）→ **シャント抵抗 + AMC3302** に置換。
> 電流chが電圧chと同じ「センサ→絶縁アンプ→AAF→ADC」構造になり、**負担抵抗 Rb / Vcmバイアス Rcm / VCM基準回路 が不要**に。
> 位相誤差（純抵抗シャント＋固定遅延の絶縁アンプ）が大幅に低減し、PMUのTVE改善に寄与する。

> **アナログ電源の位置づけ**：AMC3330/AMC3302はDC-DC内蔵のため絶縁電源は不要。ADC/AMCのアナログ3.3Vは **低ノイズLDO一段** で +5V から生成（アナロググラウンドはデジタルと1点接続）。安全絶縁はHLKとAMCが担うため、アナログ経路に絶縁DC-DC（R1SE等）は不要。**ESP32グラウンド雑音が実測で問題化した場合のみ**、R1SE（絶縁DC-DC）を追加してアナロググラウンドを島化する余地を残す。

## 2. システムブロック図

```
        危険側(AC100V, 測定線)          ┊絶縁┊            安全側(フローティング)
 L ─[F1]─[SW1]─●(L_NODE)─[Rsh 1.5mΩ]─●(L_LOAD)──────────→ 負荷へ(L)
              │  │                   │
              │ (電圧タップ)     シャント両端(±50mV)→ AMC3302(絶縁+DCDC) → AAF → ADS131M02 ch1
              │  │                                                          │
              │ 分圧(510k×3+5.1k)→ AMC3330(絶縁+DCDC) ─────────→ AAF → ADS131M02 ch0
              │  │                                                          │SPI/DRDY
   ┌──[F2]────┘  │      ← ★給電はシャント上流(L_NODE)で分岐 → Rshを通らない  │
   │(電源分岐)    │   ┊電源側の絶縁境界(HLK内蔵)┊                             │
 [HLK-10M05]─────┼─→ +5V(2A) ─┬─→ Nucleo(STM32) ──────────────────────────┤
 絶縁AC-DC 5V/2A  │            ├─→ ESP32 ─WiFi→ PC/PDC
   │            │            └─→ LDO(低ノイズ)→+3.3V_A(アナログ: ADC/AMC)
 N ●───────────●(N_NODE)────────────────────────────────→ 負荷へ(N)
        L76K GPS HAT ─UART/PPS─→ STM32(入力キャプチャ)   ↑MCO(8MHz)→ADC CLKIN
```

- **絶縁境界（信号）**：電圧ch＝AMC3330、電流ch＝**AMC3302**（いずれも容量結合の強化絶縁＋内蔵DC-DC）。
- **絶縁境界（電源）**：**HLK-10M05（絶縁AC-DC）**。AC入力＝危険側（L_NODE-N_NODE）、DC出力＝安全側。→ 安全側は測定線に対し**二重に絶縁**され、常にフローティング。MCU/ESP32/GPSは安全側。
- **自給電の要点**：分岐は**シャント Rsh より上流（L_NODE）**。HLK 1次電流は L_NODE→N_NODE を流れ **Rsh を通らない**ため、電流測定に一切影響しない。
- **両ch対称**：電圧・電流とも「センサ→絶縁アンプ→AAF→ADC」。出力コモンモードはアンプが自己生成（VDD2/2）。

## 3. 電源アーキテクチャ（測定線からの自給電）

**電源フロー**（AC-DCモジュール＋アナログ再生成）：
```
測定線 L_NODE ─[F2]─ HLK-10M05(AC100V→DC5V 2A) ═絶縁═ +5V
                                                       │
      +5V ─┬─→ Nucleo(E5V)→内蔵LDO→+3.3V_D(STM32/ADC DVDD/L76K)
           ├─→ ESP32（+5V, 470-1000µFバルク）
           └─→ LDO(低ノイズ3.3V) ─ +3.3V_A（ADC AVDD / AMC3330・3302 VDD2）
```

| レール | 供給先 | 供給元 |
|--------|--------|--------|
| （AC入力） | HLK-10M05 Vin(L/N) | **測定線 L_NODE-N_NODE（シャント上流）** 経由、F2で保護 |
| +5V | ESP32 / アナログLDO入力 / Nucleo(E5V) | **HLK-10M05 出力 5V/2A**（自給電・絶縁済） |
| +3.3V（デジタル） | STM32 / ADS131M02 DVDD / L76K | Nucleo 3.3V（E5V経由の内蔵LDO） |
| +3.3V（アナログ） | ADS131M02 AVDD / **AMC3330 VDD2 / AMC3302 VDD2** | **+5V → 低ノイズLDO一段で3.3V**（π型フィルタ後の+5V_Fから） |
| AMC3330/AMC3302 フィールド側 | （各IC内部DC-DCが自動生成） | 不要 |

- **自給電の原則**：**分岐はシャント Rsh の上流（L_NODE）**。給電電流（HLKのAC入力）は Rsh を通らず、電流測定に影響しない（誤差ゼロの必須条件）。
- **ノイズ対策（要点）**：HLK-10M05は**スイッチング方式**で出力に数十mVppのリプル＋高周波ノイズを持つ。よって
  - **アナログ系(ADC/AMC)は π型フィルタ後の+5V → 低ノイズLDO** で作り、LDOのPSRR＋フィルタでHLKノイズを落とす。
  - HLK出力直後に **π型フィルタ（10µF＋小インダクタ/フェライトビーズ＋10µF）**＋各ICデカップリングでHF成分を減衰。
  - HLKのスイッチング周波数はADC帯域(≈fs/2 3.9kHz, AAF 1.7kHz)より遥かに高く、ΔΣ＋AAFで良く落ちるが、エイリアス防止のためAAF前段のクリーン化を優先。
- **Nucleo給電**：E5Vピンへ+5V供給（ジャンパ **JP5 を E5V 側**に設定）。
- **容量マージン**：HLK-10M05=2A に対しシステムピーク約1A → 2倍の余裕。ESP32送信バーストは **ESP32直近の 470-1000µFバルク**でも吸収。
- アナロググラウンド/デジタルグラウンドは**1点（スター）接続**。**HLKの −Vout=安全側基準（DGND）**（フローティング）。AGNDとはADC直下1点で結合。
- **VCM基準回路は廃止**（電流chがアンプ自己バイアスになったため不要）。

### 3.1 自給電電源部の設計（性能を落とさないための要点）

**目的**：測定対象の商用100Vから装置電源を作りつつ、（a）電流測定に誤差を出さない（b）ADC/AMCへスイッチングノイズを持ち込まない。

**(1) 分岐点＝シャント上流（測定誤差ゼロの必須条件）**
```
 L ─[F1]─[SW1]─●(L_NODE)──[Rsh 1.5mΩ]──●(L_LOAD)──→ 負荷L
                 │  ▲(ここを通る電流=測定値)
      ┌──[F2]────┘
 [HLK Vin(L)]   ← 分岐は必ず L_NODE（Rshの上流）。
      │           HLKのAC入力電流は L_NODE→N_NODE を流れ Rsh を通らない → 測定に加算されない
 N ───●(N_NODE)── HLK Vin(N)
```
- L_LOAD（シャント下流）から取ると給電電流が Rsh を流れ負荷電流に上乗せ＝誤差。**必ず L_NODE**。
- 電圧測定への影響：HLK入力は L_NODE-N_NODE 間の負荷になるが、分圧タップの電圧読み値自体は変わらない（精度影響なし。ごく軽い電源負荷が増えるのみ）。

**(2) 消費電力の見積り（+5V換算）**

| ブロック | 平均 | ピーク | 備考 |
|----------|:---:|:---:|------|
| Nucleo（STM32＋内蔵LDO, L76K含む） | ~150mA | ~180mA | E5V給電 |
| ESP32 | ~120mA | ~500mA | WiFi送信時バースト |
| アナログ系（ADC/AMC＋LDO） | ~50mA | ~80mA | LDOで5V→3.3V、消費は小さい |
| **合計** | **~320mA** | **~0.8A** | HLK-10M05(2A)で2倍超の余裕 |

**(3) 電源モジュール（HLK-10M05）**

| 項目 | 値 | 計算/根拠 |
|------|----|----------|
| 型式 | **HLK-10M05** | 絶縁AC-DC、AC100-240V入力、DC5V 2A(10W)出力 |
| 出力容量 | **2A** | システムピーク約1Aに対し2倍余裕（5M05=1Aは不足のため不採用） |
| 出力リプル | 数十mVpp＋SWノイズ | **アナログはπ型フィルタ＋低ノイズLDOで除去** |
| 出力バルク | +5V直下 100µF＋ESP32直近 470-1000µF | ESP32送信ピーク吸収 |
| AC入力保護 | **F2：AC250V/T/0.5A** | HLK入力側ヒューズ |
| 絶縁 | 強化絶縁（データシート値） | 安全側フローティングを担保 |

- **HLKの弱点＝スイッチングノイズ**：リニア（旧T3+7805）より不利。よって**アナログ経路は π型フィルタ＋低ノイズLDO** でHF減衰・再レギュレート。
- **利点**：部品点数削減・発熱ほぼ無し（放熱器不要）・入手容易・小型。トランス入手難と7805発熱の問題を解消。

**(4) ノイズ・性能維持**
- HLK-10M05は**スイッチング方式**なので、出力に数十mVppリプル＋高周波ノイズを持つ（リニアより不利）。対策を段で重ねてADCアナログ帯域への混入を抑える：
  1. **HLK出力直後にπ型LCフィルタ**（L1＋C45/C46 10µF）でHF成分を減衰。
  2. **アナログ系(ADC AVDD / AMC VDD2)は 低ノイズLDO一段**で3.3Vを再生成 → LDOのPSRR（DC〜系統高調波で60〜80dB）でHLKリプルを除去。
  3. ADCは**ΔΣ＋AAF(1.7kHz)**。HLKのスイッチング周波数（数十〜数百kHz）は帯域外で強く減衰。ただしエイリアス防止のためAAF前段のクリーン化を優先。
- 振幅精度を決めるのはADC内蔵Vref(1.2V)であり+5Vレールではない → 5Vノイズが基本波ビンのTVEへ乗る経路は細い。
- グラウンド：**HLK −Vout＝安全側基準（DGND, フローティング）**。AGND-DGNDはADC直下1点スター（§20）。ESP32のバースト電流はDGND側に閉じ込め、AGNDへ回さない。

## 4. 電圧フロントエンド設計

AMC3330：±1Vバイポーラ入力（中点バイアス不要）・**固定ゲイン2.0**。
分圧比は「**ゲイン2倍後の出力がADC FSR(±1.2V)に収まる**」よう設定（入力範囲だけでなく出力で確認）。

| 部品 | 値 | 計算/備考 |
|------|----|----------|
| 分圧 上側 Rhi | **510kΩ ×3 直列（1.53MΩ）** | 各≈33V分担で耐圧確保。0.1%/≤25ppm/薄膜 |
| 分圧 下側 Rlo | **5.1kΩ** | 分圧比 ≈ 1/301（5.11kΩ/E96でも可）|
| 入力ピーク | 141Vpk ÷301 ≈ **0.47Vpk** | AMC3330 ±1V内 |
| AMC出力（×2）| 0.47Vpk×2 ≈ **0.94Vpk** | ADS131M02 FSR ±1.2V内（約22%余裕）|
| 分圧電流 | 約65µA（消費約6.5mW、発熱無視可） | Rhiでほぼ決まる |
| 出力コモンモード | AMC3330が VDD2/2（≈1.65V@3.3V）を生成 | ADC入力CMに整合 |

- **耐圧確認**：510kΩは working voltage ≥ 33V/本。
- **重要**：AMC3330はゲイン2なので `141Vpk × 分圧比 × 2 ≤ 1.2V` を満たすこと。
  （旧版の1/153では出力1.84Vpk＞FSRで飽和していた → Rloを10kΩ→5.1kΩに変更）

## 5. 電流フロントエンド設計（シャント抵抗 + AMC3302）

L線に低抵抗シャントを直列に挿入し、その両端電圧（±数十mV）を**絶縁シャントアンプ AMC3302**で測る。
純抵抗センスのため**位相誤差がほぼゼロ**、DCも測定可、飽和なし。**実用測定レンジ 〜10A**前提。

| 部品 | 値 | 計算/備考 |
|------|----|----------|
| シャント Rsh | **1.5mΩ**（4端子ケルビン/≤25ppm/≥1W） | 10A rms（14.1Apk）で 14.1A×1.5mΩ ≈ **21.2mVpk**（AMC3302 ±50mV内） |
| 絶縁アンプ AMC3302 | 入力±50mV / **固定ゲイン 41** | 出力差動 = 21.2mV×41 ≈ **0.87Vpk**（ADS131M02 FSR ±1.2V内）|
| ADC飽和まで | 出力1.2V→入力29.3mV→ **約13.8A rms** | 定格10Aに対し約1.4倍の余裕 |
| 発熱 | I²R = 100×0.0015 ≈ **0.15W**（10A時）| 5A時≈0.04W |
| 出力コモンモード | AMC3302が VDD2/2（≈1.65V）を生成 | ADC入力CMに整合（中点バイアス不要）|
| レンジ調整 | 小信号重視→Rsh大（2mΩ等）／大電流→Rsh小 | 「最大電流×√2×Rsh×41 ≤ 1.2V」を満たすこと |

**接続**：Rshの両端を**ケルビン(4端子)**で AMC3302 INP/INN へ。AMC3302の高圧側GND(HGND)はシャント片端へ。
出力 OUTP/OUTN を AAF経由で AIN1P/AIN1N へ。**負担抵抗・Vcmバイアス・VCM基準は不要**。

> **重要**：シャント自体は非絶縁（L線上）。絶縁はAMC3302が担う（強化絶縁＋内蔵DC-DC）。
> シャントは**低TCR・4端子**品を選び、配線抵抗を測定値に含めないこと。

## 6. アンチエイリアスフィルタ（AAF）

電圧ch・電流chで**完全同一**（位相整合のため）。差動構成。**v1.0から変更なし**。

| 部品 | 値 | 備考 |
|------|----|----|
| 直列R（各ライン） | **1kΩ ×2/ch**（0.1%/薄膜） | 両ch同一型番 |
| 差動C（Cdiff） | **47nF**（C0G/NP0 or フィルム） | fc_diff ≈ 1/(2π·2kΩ·47nF) ≈ **1.7kHz** |
| コモンモードC（Ccm） | **1nF ×2/ch**（C0G） | 各ラインからAGNDへ（任意） |

- fc≈1.7kHz は fs/2（≈3.9kHz）より十分下。50Hzで約−1.7°の群遅延 → **両ch同一化で相殺＋実測補償**。

## 8. 時刻同期（L76K GPS HAT）

- HATはPi用だが、**UART(TX/RX)・PPS・5V/3.3V・GND をSTM32へ配線**して使用（Piに挿さない）。**PPSピンが端子に出ていることを確認**。
- L76K：GPS/GLONASS/BeiDou/**QZSS(みちびき)対応**、1PPS精度 <30ns（50Hzで約0.0005°相当＝十分）。
- **PPS → STM32タイマ入力キャプチャ**（sub-µsでエッジ時刻取得）。
- UARTでNMEA/構成（PPS周波数等）を受信。屋外/窓際で運用。

## 9. 制御・通信

- **STM32 → ESP32：UART（例 921600bps）**でフェーザ結果（タイムスタンプ・V振幅/位相・I振幅/位相・f・ROCOF）を転送。

- 時刻クリティカルパスはSTM32内で完結 → WiFi遅延・ジッタはフェーザ精度に無影響（値にタイムスタンプ）。

## 12. アルゴリズム

### 12.1 取得（Acquisition）
1. STM32がMCOで8MHzをADC CLKINへ供給 → ADCは固定 fDATA(≈7812.5SPS) で**自走**。
2. **DRDY割込**ごとにSPI/DMAで2ch同時サンプル（V,I）を取得し、リングバッファへ。
3. **PPS立ち上がり**をタイマ入力キャプチャで捕捉 → そのタイマカウントを保持。
4. サンプルカウンタとPPSキャプチャ値から、各サンプルの**絶対時刻（UTC）**を復元。
   - PPS毎に基準を更新（STM32水晶のppm誤差を1秒毎にリセット）。

### 12.2 フェーザ推定（Phasor Estimation）
- 報告周期（例 **50 fps**、設定可）ごとに、UTCの基準時刻に整列した窓のサンプルを抽出。
- 基本波フェーザを **DFT** で算出：
  - `X = (2/N) Σ x[n]·e^(−j2πk0 n/N)`（k0＝基本波ビン）
  - この正規化で **|X| ＝ピーク振幅**、位相 = arg(X)（**UTC基準＝同期フェーザ**）。
  - **C37.118は振幅＝RMS慣例**のため、出力・電力計算の前に **RMS化：Vrms=|X|/√2、Irms=|X|/√2**。
- **補間DFT（Interpolated DFT, IpDFT）**で系統周波数の公称ズレを補正：
  - Hann窓を適用し、ピーク近傍の2〜3ビンから**真の周波数・振幅・位相**を補間推定。

### 12.3 周波数・ROCOF
- IpDFTで得た基本波周波数 f を出力。
- 連続する推定値から **ROCOF = df/dt**（平滑化付き差分）。

### 12.4 電力量
- **RMS化したフェーザ**（Vrms=|V|/√2, Irms=|I|/√2）から：
  - 有効電力 P = Vrms·Irms·cosφ、無効電力 Q = Vrms·Irms·sinφ、力率 = cosφ（φ＝∠V−∠I）。
  - ※ピーク振幅で計算する場合は P = ½|V||I|cosφ（1/2係数を忘れないこと）。

### 12.5 校正補償（適用順）
1. **振幅スケール**：分圧比・**シャント値 Rsh**・**AMC3302/AMC3330ゲイン**の実測係数で物理量へ換算。
2. **位相オフセット補償**：ch毎の遅れ（AMC3330/AMC3302＋AAF＋ADC）を校正テーブルで減算。
3. **AAF群遅延補償**：実測群遅延を位相から差し引く。

### 12.6 出力（C37.118）
- STM32 → ESP32（UART）：`{UTCタイムスタンプ, Vmag, Vang, Imag, Iang, f, ROCOF, status}`。
  - **Vmag/Imag は RMS値**（=|X|/√2）でC37.118に整合させる。
- ESP32：C37.118.2 データフレーム化 → WiFi送信。

## 13. 校正手順（TVEを決める要）

1. **振幅校正**：既知の基準電圧・電流を入力し、スケール係数を決定（電流は **Rsh×ゲイン** が基準）。
2. **位相校正**：同位相の基準V・I（抵抗負荷で力率≈1）を入力し、各chの位相オフセットを実測 → テーブル化。
   - シャント＋AMC3302は位相シフトが小さいので、残差はAAF群遅延が主成分。
3. **群遅延校正**：AAFカットオフ確定後、群遅延を実測し補償。
4. **検証**：基準器または既知力率負荷でTVE・力率を確認。

## 15. 安全設計（必須）

- L側に**ヒューズ（AC250V・T・ceramic HBC）＋電源SW**（F1/SW1）。**電源分岐にも専用ヒューズ F2**（HLK AC入力保護）。
- 危険側（分圧器・**シャント**・**HLK AC入力側**・配線）は**絶縁ケース＋端子カバー**で露出させない。
- **シャントはL線(活線)上にあり非絶縁**。絶縁境界（AMC3330・AMC3302・**HLK-10M05**）より先が安全側 → PC/WiFiデバッグ安全。
- **自給電の絶縁**：安全側は **HLK-10M05（電源）と AMC3330/3302（信号）の二重絶縁**で測定線からフローティング。**HLKは強化絶縁のAC-DC品**で、1次-2次の沿面/空間距離が確保されている（データシートの絶縁耐圧を確認）。非絶縁のトランスレス（コンデンサドロップ/抵抗ドロップ）電源は**禁止**（安全側が活線に浮く）。
- **HLK AC入力は必ずシャント上流（L_NODE）**。下流(L_LOAD)分岐は測定誤差の原因かつ配線が煩雑になるため不可。
- 危険側で自給電する場合、**測定側の絶縁トランス T2 は任意**。実系統をそのまま測るなら T2 を省き、装置ごと活線電位に置く運用も可（その場合こそ HLK/AMC の絶縁が生命線）。T2 を残すなら HLK AC入力は T2 2次側（=L_NODE-N_NODE）へ接続する。
- シャントの**ケルビン配線**を短く。高圧側GND(HGND)はシャント片端に確実に接続。
- **HLKのAC入力ピン（危険側）とDC出力ピン（安全側）を基板上で明確に分離**し、絶縁スリット/距離を確保。安全側配線を1次側パターンに近づけない。
- 初回は低ワット抵抗負荷から、電流を見ながら段階的に。自信が無ければ経験者立ち会い。

## 18. 既知の制約・発展

- シャント方式は**位相精度・DC測定・無飽和**が利点。一方シャントは**非絶縁・発熱**があり、大電流では抵抗値を下げてSNRとのトレードオフになる。
- L76Kは**測位・汎用グレード**（非timing）。TVE認証級を狙うならNEO-M8T等timingグレードへ格上げ。
- 単相構成。三相化＋正相算出、OCXOホールドオーバ、P/Mクラスフィルタ対応が標準PMUへの発展経路。

### 部品ピン凡例
```
抵抗/コンデンサ : .1=一端, .2=他端（無極性。電解C24はC24.1=+）
Rsh             : .1=L_NODE側, .2=L_LOAD側（電流経路）。INP/INNはケルビンで別取り出し
U1 AMC3330      : INP,INN,HGND,OUTP,OUTN,VDD2(=VDD),GND2(=GND) ＋DC-DC系
                  (DCDC_OUT,DCDC_HGND,HLDO_IN,HLDO_OUT,LDO_OUT,DCDC_IN,DCDC_GND,DIAG,NC)
U5 AMC3302      : 同上（±50mV入力のシャント用絶縁アンプ）
U2 ADS131M02    : AVDD,AGND,DVDD,DGND,CAP,AIN0P,AIN0N,AIN1P,AIN1N,
                  CLKIN,SCLK,DIN,DOUT,/CS,/DRDY,/SYNC-RESET
U4 ADP7142(LDO) : VIN(→+5V_F), GND(→AGND), EN(→VIN 常時ON), SENSE/ADJ(→VOUT), VOUT(→+3.3V_A)
                  TSOT-23-5: 1=VIN,2=GND,3=EN,4=SENSE,5=VOUT。入出力C≥2.2µF（C16/C18=10µF）

L1              : .1=+5V(HLK直後), .2=+5V_F（πフィルタ直列素子。大電流ﾋﾞｰｽﾞ≥2A/DCR≤50mΩ 例:村田BLM31）
```

> AMC3330/AMC3302のDC-DC系ピン（DCDC_OUT/HLDO_IN/HLDO_OUT/LDO_OUT/DCDC_IN/DCDC_GND/DCDC_HGND）は
> データシート(SBASA34B等)の指定どおり相互接続し、高圧側Cは各IC HGND、低圧側Cは各IC GNDへ戻すこと。
